# Agent Instructions

This is a set of scripts to control a Home Assistant

## Reference docs

- background.md contains the background and aims for managing the car charging
- README.md contains a summary of the scripts, and other instructions for humans. Do not lose data
- reference.md lists the available states for the my particular devices connected to the Home Assistant
  - Ohme Pro charge
  - HomeWizard P1 port reader

## Combine

- Do not attempt to run `combine.py` after each change

## Git & Commits

- NEVER perform `git commit` or `git push` unless explicitly asked by the user.
- You may use `git add` to stage files if it helps their workflow.
- Assume the user wants to review and commit changes themselves.
