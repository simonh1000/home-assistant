2 Ohme — huidige opstelling Ohme — current setup
Doel: enkel verifiëren wat er al staat — pure visuele inspectie. Geen instellingen wijzigen op de Ohme; dat loopt apart via de Ohme-installateur. Aim: just verify what's already there — pure visual inspection. Do not change any Ohme settings; that's running separately via the Ohme installer.
Ohme-laadpaal — wat we zoeken / what we're looking for Verwacht: 3 CT-klemmen, één per fase, dicht bij de hoofdmeter, pijl richting het huis. We denken dat alle 3 al geplaatst zijn, maar dit is nooit bevestigd. Graag tellen, richting controleren, en close-up foto's nemen van elke klem. Geen instellingen wijzigen in de Ohme-app. Volgens het schema van Hendrickx & Co is er een aparte 3-fasige 32A-voeding (kabel XVB 5G6) die hier vermoedelijk bij hoort — ter plaatse bevestigen. Expected: 3 CT clamps, one per phase, close to the main meter, arrow toward the house. We believe all 3 are already fitted, but this was never confirmed. Please count, check direction, and take close-up photos of each clamp. Do not change any Ohme app settings. The Hendrickx & Co diagram shows a separate three-phase 32A feed (cable XVB 5G6) that's presumably this circuit — confirm on site.

3 EcoFlow — wat moet gebeuren EcoFlow — what needs to happen
Doel: dit is het nieuwe werk van vandaag — de driefasige opstelling en de netwerktoegang die Home Assistant nodig heeft. Aim: this is today's actual new work — the three-phase setup and the network access Home Assistant needs.
EcoFlow 3-fasig herkennen / How to recognize the 3-phase EcoFlow unit De omvormer en de batterij bestaan in aparte 1-fasige en 3-fasige hardware-uitvoeringen — niet gewoon dezelfde doos anders bekabeld. Verwacht typeplaatje: HD-P3-6K0-S1 (bevestigd via getekende offerte). Extra controle indien twijfel: de AC-kabel naar de omvormer moet 5 aders hebben (3 fasen + nul + aarde) i.p.v. 3.
The inverter and battery exist as genuinely separate single-phase and three-phase hardware. Expected nameplate: HD-P3-6K0-S1 (confirmed via signed quote). Extra check if in doubt: the AC cable into the inverter should have 5 cores (3 phases + neutral + earth), not 3.
EcoFlow: verwacht de driefasige meter/CT-klemmen (bevestigd door verkoper op 21 aug) — bevestigen dat dit geplaatst wordt. (Let op: de offerte vermeldt zelf een "1-fase CT" — dit is de echte openstaande vraag, niet het omvormermodel.)
EcoFlow: expecting the three-phase meter/CT clamps (confirmed by sales rep 21 Aug) — confirm that's what's fitted. (Note: the quote itself lists a "1-phase CT" — this is the real open question, not the inverter model.)
Krijgt de omvormer een vast IP-adres / netwerktoegang binnenshuis? (nodig voor Home Assistant — de P1-poort werkt zelf al goed via HomeWizard P1)
Will the inverter get a fixed IP address / in-home network access? (needed for Home Assistant — the P1 port itself already works fine via HomeWizard P1)
De PowerOcean heeft blijkbaar een Modbus TCP-interface, maar die zit vergrendeld achter een "installer unlock." Kan de installateur dit tijdens de commissioning ontgrendelen? Dat geeft echte lokale, real-time data i.p.v. trage cloud-polling — dezelfde stap vooruit als de HomeWizard P1 al gaf. Gewoon rechtstreeks vragen, niet aannemen dat enkel de cloud kan.
The PowerOcean apparently has a Modbus TCP interface, but it's locked behind an "installer unlock." Can the installer enable this during commissioning? That would give genuine local, real-time data instead of laggy cloud polling — the same kind of upgrade the HomeWizard P1 already gave. Worth asking outright rather than assuming cloud-only is the only option.
Is er een exportlimiet (terugleverlimiet) ingesteld op de omvormer? Komt dit overeen met wat we verwachten gegeven de paneelcapaciteit (5,7 kWp)?
Is there a configured grid export/feed-in limit on the inverter? Does it match what we'd expect given the panel capacity (5.7 kWp)?
Welke circuits blijven gevoed door de S1-batterij bij een stroomstoring (backup)? Niet het hele huis, vermoedelijk — welke wel?
Which circuits stay powered by the S1 battery during a grid outage (backup)? Presumably not the whole house — which ones are?
Is er fysieke/elektrische ruimte om later een tweede S1-module toe te voegen, zonder de installatie te moeten herdoen? (relevant gezien we bewust overdimensioneren met het oog op wederverkoop)
Is there physical/electrical headroom to add a second S1 module later, without redoing the install? (relevant given we're deliberately over-building with resale value in mind)
Garantietermijnen genoteerd? Productgarantie (EcoFlow) en installatiegarantie (Dural) zijn normaal apart — beide termijnen apart vastleggen.
Warranty terms on file? Product warranty (EcoFlow) and installation warranty (Dural) are normally separate — record both durations separately.
